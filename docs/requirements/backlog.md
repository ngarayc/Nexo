# Backlog sintetico para el flujo con IA

## EP-01 - Panel de estados
Como operador quiero ver el estado mas reciente de la flota y recibir actualizaciones automaticamente.

## EP-02 - Ingesta confiable
Como sistema quiero recibir lotes de eventos, con validacion, idempotencia y tolerancia a eventos desordenados.

## EP-03 - Alertas
Como supervisor quiero identificar eventos de exceso de velocidad (>80 km/h).

## CR-01 - Cambio de requisito
Como producto quiero un filtro de alertas por identificador de vehiculo. El cambio debe pasar por el mismo flujo de planificacion, implementacion y revision.
